🧠 One SQL query. 4 powerful concepts.
If you're working with cricket match data (or any sports/sales data), this query is a goldmine to understand.

Here's what it does 👇

Find every match winner and their total winning margin — ranked highest to lowest.

1SELECT match_winner,
2    SUM(CASE
3        WHEN Win_Margin = 'NULL' OR Win_Margin IS NULL
4        THEN 0
5        ELSE CAST(Win_Margin AS BIGINT)
6    END) AS total_win_margin
7FROM match
8GROUP BY match_winner
9ORDER BY total_win_margin DESC;

🔍 Let's break it down — clause by clause:

SELECT
Picks the winner's name + calculates their aggregated win margin.
CASE WHEN
Guards against dirty data — handles both string 'NULL' and actual NULL values safely.
CAST AS BIGINT
Converts the margin (stored as text) to a number so SUM() can actually add them up.
GROUP BY
Collapses all rows per team into one row, enabling SUM() to aggregate across matches.
ORDER BY DESC
Sorts the final result so the dominant team (highest margin) appears first — great for leaderboards.

⚠️ The sneaky trick: double NULL check

When data is imported from CSV/Excel, missing values often land as the string 'NULL' — not a real SQL NULL. This query handles both:

  • Win_Margin = 'NULL' → catches string 'NULL'
  • Win_Margin IS NULL → catches actual database NULLs

💡 Key SQL concepts inside this one query:

1Conditional aggregation using SUM(CASE WHEN ...)
2Type casting with CAST(... AS BIGINT)
3NULL-safe filtering before aggregation
4Grouping + sorting for ranked output

📌 Save this pattern — you'll use it anytime you need to safely aggregate messy numeric columns from raw data imports.
